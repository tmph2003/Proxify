# Python Design Patterns Rule
Khi thiết kế kiến trúc hoặc refactor code Python trong dự án này:
1. BẮT BUỘC đọc và áp dụng các nguyên tắc từ skill `python-design-pattern`.
2. Tránh các Anti-pattern (God Object, Tightly Coupled, Lạm dụng kế thừa).
3. Trước khi đề xuất một cấu trúc code mới phức tạp, hãy phân tích xem nó đang dùng Pattern nào và tại sao pattern đó lại phù hợp.
