## Usability Cheatsheet

### Decision Rules
- **If the user has to think about what to click,** you have failed the First Law of Usability. Make it obvious.
- **If a feature requires a manual or instructions,** users will muddle through and likely fail. Simplify the interface instead of writing better instructions.
- **If a page is wordy,** cut the word count in half. Then cut the remaining words in half again.
- **If arguing about design (Religion),** stop arguing and test it on a user.

### The Trunk Test Checklist
Can a user answer these instantly?
- [ ] What site is this?
- [ ] What page am I on?
- [ ] What are the major sections?
- [ ] What are my options here?
- [ ] Where am I in the site hierarchy?
- [ ] How can I search?

### Testing Heuristics
- **Test early:** Test before you have code (sketches, competitors).
- **Test small:** 3 users are enough to find the biggest problems.
- **Test often:** Make it a monthly morning habit.
