## Core Frameworks & Mental Models

- **Feature-driven Design**: Don't design the whole app up front. Design feature by feature.
- **Use multiples of a base unit**: For spacing, sizing, etc., use multiples of a base unit (e.g., 4px or 8px) to create a rhythmic layout.
- **Hierarchy is everything**: Not all elements are equal. Use size, weight, color, and contrast to guide the user's eye.
- **Design in grayscale first**: It forces you to focus on spacing, contrast, and hierarchy without being distracted by color.
- **Don't use gray text on colored backgrounds**: Reduce opacity instead of using a lighter gray to make text blend harmoniously with colored backgrounds.
