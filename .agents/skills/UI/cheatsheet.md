## Refactoring UI Cheatsheet

### Decision Rules
- **If text feels cramped,** increase line-height. (Base: 1.5 for body text, 1.2 for headings).
- **If the design feels flat,** add subtle drop shadows or slightly overlap elements.
- **If elements feel disconnected,** decrease the space between them (grouping). Increase space between distinct groups.
- **If you need secondary text,** don't just use a smaller font. Try a lighter font weight or a softer color (e.g., gray).

### Color Rules
- Use HSL for defining color palettes. Adjust Lightness to create shades.
- Don't use pure black. Use a very dark gray (e.g., #111827) for softer contrast.
- When placing text on an image, add a subtle dark gradient overlay to ensure readability.
